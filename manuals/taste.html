Taste

Design critique, aesthetic curation, and UI evaluation skill for ensuring high visual polish in software.

#ai-skills #design #critique #ui-ux
Official Docs

What It Is

Taste is a design critique, aesthetic curation, and UI evaluation skill dedicated to ensuring software interfaces feel intentional, harmonious, and crafted with editorial polish.

Rather than settling for generic templates or cluttered screens, Taste evaluates color restraint, typographic hierarchy, whitespace balance, contrast legibility, and subtle micro-interactions.

How It Helps With Your Projects

  • Disciplined Color Harmony: Enforces strict adherence to curated palettes (such as EC-Tools’ 5-hex rotational system) so every badge, border, and surface feels cohesive.
  • Clear Typographic Hierarchy: Pairs expressive display headings (Plus Jakarta Sans) with readable body copy (Inter) and crisp code blocks (JetBrains Mono).
  • Tactile Micro-Interactions: Adds purposeful hover elevations, focus rings, and smooth transitions without visual clutter or bloat.
When to Reach for Taste: Apply Taste whenever designing new pages, styling components, or auditing an interface before launch to ensure visual consistency and readability across all themes.

How to Use It

Run aesthetic audits on UI layouts before launch. Check color harmony, typography hierarchy, whitespace balance, and micro-interactions for a WOW impression.

  1. Restrict all new UI elements to your project’s canonical CSS custom properties instead of inventing one-off hex colors.
  2. Check contrast and legibility across every theme variation (light, warm cream, sage, obsidian, and pitch black).
  3. Give headings, cards, and callout boxes generous breathing room and clear visual hierarchy.
/* Taste Checklist in CSS */
.manual-readme-card {
  background-color: var(--bg-card);       /* Strictly uses theme surface token */
  border: 1px solid var(--border-color);  /* Subtle editorial border */
  border-radius: var(--radius-xl);        /* Harmonized corner radius */
  box-shadow: var(--shadow-card);         /* Soft layered elevation */
}
