Brevo

Transactional email, SMTP relay, and messaging API platform with open-source SDKs for automated notifications and campaigns.

#open-source #email #smtp #transactional #api
Official Docs

What It Is

Brevo (formerly Sendinblue) is a developer-friendly transactional email, SMTP relay, and messaging API platform with official open-source SDKs for sending automated notifications, OTP codes, and system alerts.

It provides a generous free tier, reliable inbox deliverability, dynamic HTML templates, and both REST API and standard SMTP integration options.

How It Helps With Your Projects

  • Reliable Transactional Emails: Send instant account verification OTPs, password reset links, order receipts, and contact form notifications that land in the inbox.
  • REST API or Drop-In SMTP: Integrate via simple HTTPS POST requests or plug standard SMTP credentials into Nodemailer, FastAPI, or Supabase Auth.
  • Dynamic Branded Templates: Design reusable email templates with variables ({{params.userName}}, {{params.otpCode}}) and trigger them with a single API call.
When to Reach for Brevo: Use Brevo whenever your web application needs to send automated emails—such as registration OTPs, password resets, or portfolio contact alerts.

How to Use It

Integrate via REST API or SMTP to send transactional emails (OTP verification codes, password resets, welcome emails, and system alerts). Store your API key securely in .env and use dynamic templates for consistent branding.

  1. Generate an API key (or SMTP key) in your Brevo dashboard and store it in your backend .env file as BREVO_API_KEY.
  2. Verify your sender email address or custom domain (DKIM/SPF) to ensure high inbox deliverability.
  3. Send transactional emails from your backend server (never expose your Brevo API key in client-side browser code).
// Sending a transactional email via Brevo REST API (Node.js fetch)
await fetch('https://api.brevo.com/v3/smtp/email', {
  method: 'POST',
  headers: {
    'accept': 'application/json',
    'api-key': process.env.BREVO_API_KEY,
    'content-type': 'application/json'
  },
  body: JSON.stringify({
    sender: { name: 'EC-Tools System', email: 'noreply@example.com' },
    to: [{ email: userEmail }],
    subject: 'Your Verification Code',
    htmlContent: '<p>Your verification code is <strong>482910</strong>.</p>'
  })
});
