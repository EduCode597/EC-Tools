Supabase

Open-source Firebase alternative providing a dedicated PostgreSQL database, Auth, Storage, and Realtime APIs.

#database #postgres #auth #backend-as-a-service
Official Docs

What It Is

Supabase is an open-source Backend-as-a-Service (BaaS) built on top of a dedicated PostgreSQL database. It pairs full relational Postgres power with instant authentication, auto-generated REST/Realtime APIs, and S3-compatible file storage.

Unlike proprietary NoSQL backends, Supabase gives you a real SQL database with Row-Level Security (RLS) so you never lose relational queries or portability.

How It Helps With Your Projects

  • Ship Auth & Database in Minutes: Enable email/password, Magic Links, and GitHub/Google OAuth without writing boilerplate auth servers.
  • Row-Level Security (RLS): Write declarative Postgres policies so users can only read or update rows they own, securing direct client queries.
  • Realtime & Storage Included: Subscribe to live Postgres table changes over WebSockets and store user avatars or documents in managed buckets.
When to Reach for Supabase: The go-to backend for solo full-stack projects, hackathons, and SaaS MVPs when you want Postgres, Auth, and Storage ready on day one.

How to Use It

The go-to choice for solo projects: get instant auth (OAuth, Magic Link), Postgres with Row-Level Security (RLS), auto-generated REST/GraphQL endpoints, and bucket file storage in minutes.

  1. Create a project in the Supabase Dashboard and store SUPABASE_URL and SUPABASE_ANON_KEY in your environment variables.
  2. Enable Row-Level Security (RLS) on every public table and define explicit SELECT/INSERT/UPDATE policies.
  3. Use @supabase/supabase-js on the client or server for type-safe queries and session management.
import { createClient } from '@supabase/supabase-js';

const supabase = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);

const { data, error } = await supabase
  .from('tools')
  .select('id, name, category')
  .eq('category', 'Database');
