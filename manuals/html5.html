HTML5

Standard markup language for documents designed to be displayed in a web browser.

#frontend #core #markup #web
Official Docs

What It Is

HTML5 is the foundational markup language of the web. It defines the structural meaning and hierarchy of every web page, dashboard, and web application before any styling or interactivity is applied.

Rather than using generic containers everywhere, HTML5 provides descriptive semantic landmarks (<header>, <nav>, <main>, <section>, <article>, <footer>) so browsers, search engines, and screen readers immediately understand how your interface is organized.

How It Helps With Your Projects

  • Built-in Accessibility & SEO: Semantic landmarks give assistive technologies and search crawlers a clear document outline with zero extra JavaScript.
  • Native Form Validation & Controls: Input types like email, date, url, and search plus required and pattern attributes validate user input right in the browser.
  • Zero-Dependency Longevity: Clean HTML5 works everywhere, loads instantaneously on GitHub Pages, and forms a rock-solid base for progressive enhancement.
When to Reach for HTML5: Start every web interface by sketching its document outline in pure semantic HTML5 before reaching for CSS layouts or JavaScript state.

How to Use It

Use semantic elements (<header>, <nav>, <main>, <section>, <article>, <footer>) for SEO and accessibility. Ensure all forms have labels and ARIA attributes for clean personal tools and dashboards.

  1. Wrap top-level regions in <header>, <main>, <aside>, and <footer> instead of nested <div> tags.
  2. Keep a single <h1> per page and maintain a logical heading hierarchy (<h1> → <h2> → <h3>).
  3. Always pair <input> elements with explicit <label for="..."> tags and descriptive aria-label attributes on icon buttons.
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Project Title</title>
</head>
<body>
  <header>...</header>
  <main>
    <section aria-labelledby="section-heading">
      <h1 id="section-heading">Dashboard Overview</h1>
    </section>
  </main>
  <footer>...</footer>
</body>
</html>
