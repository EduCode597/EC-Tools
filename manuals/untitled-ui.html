Untitled UI

The ultimate UI kit and design system for Figma, featuring thousands of modern components, charts, and icons.

#platform #design-system #figma-kit #saas-ui
Official Docs

What It Is

Untitled UI is one of the largest and most comprehensive Figma UI kits and design systems in the world, packed with thousands of accessible components, dashboard templates, data tables, and typographic scales.

It serves as both a starter kit for Figma wireframes and a masterclass reference for clean, modern SaaS interface design.

How It Helps With Your Projects

  • Proven SaaS Layout Patterns: Reference battle-tested sidebar navigation, filter bars, badge pills, and settings panels that feel immediately intuitive to users.
  • Consistent Spacing & Type Scales: Demonstrates how subtle borders, neutral surface layers, and tight font-weight contrast create a premium editorial look.
  • Accelerates Design-to-Code: Saves hours of guesswork on button states, empty states, form inputs, and card proportions.
When to Reach for Untitled UI: Consult Untitled UI when designing dashboards, directories, or multi-view web apps that need clean, timeless UI ergonomics.

How to Use It

Speed up frontend development by borrowing proven SaaS dashboard layouts, clean data tables, card designs, and button styles. Excellent inspiration for clean, minimalist interfaces.

  1. Browse Untitled UI’s component patterns for cards, badges, search bars, and empty states when planning a new screen.
  2. Adopt its 4px/8px spacing rhythm and subtle 1px border dividers to keep dense information scannable.
  3. Adapt the structural patterns to your own brand color tokens so your app feels both familiar and uniquely yours.
