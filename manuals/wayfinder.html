Wayfinder

Pathfinding and architectural navigation skill for tracing relationships, project hierarchies, and dependency graphs.

#ai-skills #architecture #navigation #graph
Official Docs

What It Is

Wayfinder is an architectural navigation and pathfinding skill focused on tracing file relationships, module hierarchies, and data-flow paths across unfamiliar or growing codebases.

When you open a repository with dozens of interconnected files, Wayfinder helps map where entry points live, how state flows between modules, and which files are impacted by a change.

How It Helps With Your Projects

  • Rapid Codebase Onboarding: Quickly locates entry points, routing tables, data stores, and shared utilities when exploring a new project.
  • Safe Refactoring Impact Analysis: Traces upstream callers and downstream dependencies before you rename functions or restructure folders.
  • Prevents Circular Dependencies: Highlights tangled module imports early so your project architecture stays modular and clean.
When to Reach for Wayfinder: Reach for Wayfinder when onboarding into an existing repo, planning a multi-file refactor, or tracing how a user action flows from UI click to data layer.

How to Use It

Employ when jumping into new repositories or multi-module projects to map dependencies, trace entry points, and identify circular links quickly.

  1. Start at the application entry point (e.g., index.html and js/app.js) and trace which data files and stylesheets it loads.
  2. Map out the core interfaces between modules (what each file exports and what neighboring files consume).
  3. Verify that new features follow the existing folder boundaries before creating new files.
