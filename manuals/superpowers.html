Superpowers

Agentic skills and composable capability extensions enabling LLMs to interact with tools, browsers, and environments.

#ai-skills #agentic #automation #tools
Official Docs

What It Is

Superpowers is an open-source agentic skills framework that equips AI coding assistants with structured workflows for brainstorming, writing implementation plans, test-driven development (TDD), systematic debugging, and code review.

Instead of letting an AI jump straight into guessing and writing untested code, Superpowers enforces disciplined engineering habits: clarify requirements first, write a crisp spec and plan, watch tests fail before implementing, and verify output before claiming completion.

How It Helps With Your Projects

  • Prevents Premature or Wrong Builds: The brainstorming skill uncovers edge cases and aligns on a clear design spec before a single line of production code is touched.
  • Strict Red-Green-Refactor TDD: Guarantees every feature or bugfix starts with a failing automated test, eliminating regressions and untested assumptions.
  • Repeatable Multi-Step Execution: Breaks large features into bite-sized, verifiable tasks saved in docs/superpowers/specs/ and docs/superpowers/plans/.
When to Reach for Superpowers: Activate Superpowers at the start of any new feature, architectural refactor, or tricky bugfix to keep AI pair-programming structured, verifiable, and high quality.

How to Use It

Equip AI agents with custom reasoning skills, automated task workflows, and repeatable tool patterns. Store specialized prompts and tool schemas in project agent configs.

  1. Start creative or feature work with the brainstorming skill to align on intent, constraints, and a written design spec.
  2. Use writing-plans to decompose the approved spec into granular tasks with explicit file paths and test steps.
  3. Execute each task using test-driven-development (RED → GREEN → REFACTOR) and verification-before-completion.
# Typical Superpowers Project Workflow
1. Brainstorm  -> docs/superpowers/specs/YYYY-MM-DD-feature-design.md
2. Plan        -> docs/superpowers/plans/YYYY-MM-DD-feature.md
3. TDD Cycle   -> Write failing test -> Verify RED -> Implement -> Verify GREEN
4. Verify      -> Run full test suite before claiming completion
