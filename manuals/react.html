React

The library for web and native user interfaces based on reusable components and declarative state.

#frontend #components #spa #ui
Official Docs

What It Is

React is a component-based JavaScript library for building interactive user interfaces. Instead of manually mutating DOM nodes, you declare what the UI should look like for any given state, and React keeps the DOM in sync.

By breaking complex screens into composable components and custom hooks, React makes large-scale single-page applications (SPAs) and dashboards predictable and easy to maintain.

How It Helps With Your Projects

  • Reusable Component Architecture: Build buttons, modals, data tables, and cards once and compose them across every view in your application.
  • Declarative State & Hooks: Encapsulate data fetching, local storage syncing, and form state inside clean custom hooks like useFetch or useLocalStorage.
  • Massive Ecosystem: Pair seamlessly with Vite, Tailwind CSS, React Bits, and Vercel for rapid full-stack product delivery.
When to Reach for React: Choose React when your project has multiple views, shared client-side state, authenticated user flows, or complex interactive forms.

How to Use It

Use when creating multi-view single page applications with complex state. Pair with Vite for rapid project scaffolding and use custom hooks (e.g. useLocalStorage, useFetch) to separate UI from logic.

  1. Scaffold new projects with Vite (npm create vite@latest my-app -- --template react) for instant hot module replacement.
  2. Keep components focused on presentation and extract reusable business logic into custom hooks.
  3. Lift shared state only as high as needed, and colocate component-specific state close to where it is rendered.
import { useState } from 'react';

export function ToolSearch({ tools }) {
  const [query, setQuery] = useState('');
  const visible = tools.filter(t =>
    t.name.toLowerCase().includes(query.toLowerCase())
  );

  return (
    <input
      value={query}
      onChange={e => setQuery(e.target.value)}
      placeholder="Search tools..."
    />
  );
}
