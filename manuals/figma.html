Figma

Collaborative cloud-based interface design, prototyping, and wireframing platform used by product designers.

#platform #design #wireframing #prototyping
Official Docs

What It Is

Figma is the industry-standard collaborative interface design, wireframing, and interactive prototyping platform that runs directly in the browser.

It bridges the gap between idea and code by letting you test layouts, define reusable color/typography variables, build responsive Auto Layout components, and inspect exact CSS measurements before writing markup.

How It Helps With Your Projects

  • Rapid Visual Iteration: Compare multiple layout directions side-by-side in minutes before committing hours to frontend implementation.
  • Auto Layout = Flexbox Mental Model: Figma’s Auto Layout mirrors CSS Flexbox (direction, gap, padding, hug/fill), making the translation to code seamless.
  • Clean SVG & Asset Export: Design and export crisp brand logos, favicons, and custom diagrams (like Madriaga_logo.svg) directly into public/.
When to Reach for Figma: Use Figma before building new user interfaces to lock in your color palette, spacing rhythm, and component hierarchy.

How to Use It

Use for high-fidelity wireframing before writing code. Define design tokens (colors, spacing, typography), auto-layout components, and export SVGs directly for web apps.

  1. Set up local Variables/Styles for your canonical color palette and typography scale before drawing screens.
  2. Build cards, navbars, and buttons with Auto Layout (Shift + A) so they resize naturally with content.
  3. Export icons and logos as clean, optimized SVGs for crisp rendering at any screen density.
/* Translating Figma Auto Layout tokens directly to CSS */
.figma-card {
  display: flex;
  flex-direction: column;
  gap: 12px;           /* Figma Item Spacing: 12 */
  padding: 20px 24px;  /* Figma Padding: 20v 24h */
  border-radius: 14px; /* Figma Corner Radius: 14 */
}
