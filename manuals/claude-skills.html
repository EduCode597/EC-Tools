Claude Skills

Structured tool-use definitions, prompt templates, and system instructions tailored for Claude & agentic workflows.

#ai-skills #anthropic #tool-use #prompts
Official Docs

What It Is

Claude Skills are structured tool-use definitions, reusable prompt instructions, and domain-specific capability modules that teach AI agents how to perform specialized engineering or creative tasks reliably.

By combining a clear YAML frontmatter trigger description with step-by-step markdown instructions and JSON tool schemas, Claude Skills turn ad-hoc prompting into deterministic, repeatable workflows.

How It Helps With Your Projects

  • Deterministic Tool Calling: Defines strict input_schema JSON contracts so LLMs pass validated arguments to APIs, file editors, and search tools.
  • Reusable Domain Expertise: Packages your team’s coding standards, review checklists, and deployment rules into modular SKILL.md files.
  • Context-Efficient Loading: Agents read the lightweight skill description first and load the full instruction manual only when the task matches.
When to Reach for Claude Skills: Use Claude Skills when building AI-powered features with Anthropic’s Tool Use API or when authoring custom SKILL.md workflows for your coding agent.

How to Use It

Implement structured JSON tool definitions (name, description, input_schema) to give LLMs deterministic API-calling capabilities, file editing abilities, and external data lookup.

  1. Write a clear name and trigger description in YAML frontmatter so the agent knows exactly when to activate the skill.
  2. Provide concrete, step-by-step instructions, guardrails, and examples inside the skill body.
  3. When using the Anthropic API directly, define each tool with a clear name, description, and JSON Schema input_schema.
{
  "name": "lookup_tool_manual",
  "description": "Retrieve the user manual and setup guide for a specific developer tool by ID.",
  "input_schema": {
    "type": "object",
    "properties": {
      "tool_id": { "type": "string", "description": "Unique slug such as 'supabase' or 'redis'" }
    },
    "required": ["tool_id"]
  }
}
